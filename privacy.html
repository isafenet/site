Website privacy

This page covers the iSafeNet company website, isafenet.app. Each app has its own Privacy Policy, linked below.

What this website collects

Nothing. This website has no cookies, no analytics, no advertising and no tracking. It doesn't ask for or store any personal information, and its fonts and images are served from this site rather than from third parties.

Hosting

The site is a set of static pages hosted by GitHub Pages. Like any web host, GitHub may keep standard server logs (such as IP addresses) to keep the service secure and running; see GitHub's own privacy statement for details.

If you email us

If you write to info@isafenet.app, we use your message and email address only to reply to you, and we don't share them.

Our apps

Each app explains exactly how it handles your data: AirReveal Privacy Policy and GLPMGR Privacy Policy.

Changes

If this ever changes, we'll update this page. Last updated 23 September 2026.
